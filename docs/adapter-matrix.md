# Adapter support matrix

**Tier:** **deep** = reopens the exact items (files, tabs, drafts, notes…). **partial** = reopens some items or the right place, with known gaps. **launch-only** = opens or focuses the app. Any app not listed falls back to **launch-only** through the generic adapter (by bundle id).

**Verified** column, for this Mac (macOS 27.0.1):

- **Live**: actually ran against real apps or data on this Mac.
- **Dict**: the scripting dictionary terms used were confirmed in the app's own `.sdef`.
- **Unit**: covered by automated tests with mocked app responses.
- **Untested**: built from vendor docs or community sources; the app isn't installed here or would need a permission I couldn't grant from the build environment.

Every restore is **open-only**: it focuses an existing item, otherwise opens it (a new tab or window). It never closes, edits, saves, sends, types, clicks, or runs commands.

## Always on

| Item                                         | Tier                        | Notes                                                                                                                  |
| -------------------------------------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Any other app                                | launch-only                 | Generic adapter: `open -b <bundle id>` (focuses if running). Document paths from its windows reopen with the same app. |
| Window positions                             | partial, **off by default** | Captured always; applied only when Settings → Restore → **Arrange windows** is on (System Events `position`/`size`).   |
| Password managers, Keychain, System Settings | excluded                    | Never captured or restored.                                                                                            |
