# Adapter research: how to capture and reopen each app's state

Research date: 2026-11-10, on macOS 27.0.1 (build 26A434), Apple Silicon.

Verification levels used below:

- **[local]**: verified on this Mac by reading the app's scripting dictionary (`.sdef` inside the app bundle, read with `grep`; no Automation permission needed), by reading a _copy_ of the app's own state files, or by running the command.
- **[docs]**: verified against the vendor's current documentation.
- **[community]**: only community sources were found (forums, gists), so treat as best-effort and mark untested where not installed.

## Reading window titles without Screen Recording

- `CGWindowListCopyWindowInfo` redacts `kCGWindowName` to an empty string without the Screen Recording permission (macOS 12.3+). Apple says which keys are populated without the permission is undocumented and may change ([Apple Dev Forums 126860](https://developer.apple.com/forums/thread/126860), [839069](https://developer.apple.com/forums/thread/839069)). **Rejected.**
- The Accessibility API (`AXUIElementCopyAttributeValue` + `kAXTitleAttribute`) reads titles with only the Accessibility permission ([Apple Dev Forums 794253](https://developer.apple.com/forums/thread/794253)). It sometimes returns no data even when permitted ([703188](https://developer.apple.com/forums/thread/703188)), so every call needs a timeout and an empty-result fallback.
- **Chosen:** System Events via `osascript` (JXA), reading `name`, `bundle identifier`, `frontmost` of `processes whose background only is false`, and for each window `title` (`name`), `position`, `size`, and the `AXDocument` attribute (file URL of the document for document-based apps). [local]: System Events' sdef exposes `process`, `window`, `title`, `position`, `size`, `attribute`, `bundle identifier`, `frontmost`. This needs **Accessibility** (System Events GUI scripting) plus the one-time **Automation → System Events** consent. No Screen Recording.
- Without Accessibility, Waypoint degrades to `NSWorkspace`-level info: the frontmost app and running apps via `lsappinfo` / System Events process list (no windows). Capture still works through per-app adapters that use their own dictionaries (Automation), and through file-based capture (VS Code state, Firefox sessionstore, git).

## Browsers

| App                                             | Capture                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Restore                                                                                                                                                                                                                                                                                                                                                          | Level                                 |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| **Chrome** (and Chromium: Brave, Edge, Vivaldi) | **[local]** Chrome `scripting.sdef` has `window.mode` ("normal"/"incognito"), `active tab index`, `tab.URL`, `tab.title`, `window.bounds`. Capture reads windows `whose mode is "normal"` only, so incognito is never read.                                                                                                                                                                                                                             | Check every tab's URL for a match. If found, `set active tab index` + `set index of window to 1` (focus). Otherwise `make new tab at end of tabs of window 1 with properties {URL:u}` in a new tab. Never sets `URL` of an existing tab. The Chrome dictionary has `make` and `URL` [local]. Brave/Edge/Vivaldi share the dictionary [community]; untested here. | deep (Chrome); deep untested (others) |
| **Arc**                                         | AppleScript windows/tabs/spaces; tab ids are UUIDs and tabs are selected with `select` ([Arc AppleScript API](https://browserinc.notion.site/Arc-AppleScript-API-897272210c784627ba3925a7610b02b6), [pokutuna arc.ts](https://glama.ai/mcp/servers/@pokutuna/mcp-chrome-tabs/blob/62911c08e36dcaf9d726094f6026a2aa40f517a4/src/browser/arc.ts)). Incognito windows: the dictionary has `incognito` on window [community]. Little Arc has no dictionary. | Existing tab → `select`; else `make new tab with properties {URL:u}`.                                                                                                                                                                                                                                                                                            | deep (untested)                       |
| **Safari**                                      | **[local]** Safari.sdef exposes `tab` with `URL`/`name` and the standard `document`/`window`. **Safari does not expose whether a window is private** ([alexwlchan](https://alexwlchan.net/2021/detect-private-browsing/)). So that private browsing is never captured, **Safari tab capture is off by default** and is opt-in in Settings, with a title heuristic as an extra guard.                                                                    | Match existing → `set current tab of w to t` + `set index of w to 1`. Else `make new tab` with `URL` and set it current.                                                                                                                                                                                                                                         | deep restore, opt-in capture          |
| **Firefox**                                     | No AppleScript. Read-only capture from `~/Library/Application Support/Firefox/Profiles/*/sessionstore-backups/recovery.jsonlz4` ("mozLz40\0" + 4-byte size + LZ4 block) ([dend.ro](https://blog.dend.ro/decoding-firefox-session-store-data/)). Private windows are not normally persisted, and any window with `isPrivate: true` is dropped.                                                                                                           | `open -a Firefox <url>` (opens a new tab; Firefox can't be asked whether a URL is open, so Waypoint dedupes against its own last capture only).                                                                                                                                                                                                                  | partial (untested; not installed)     |

## Excluded by rule

Password managers and keychain apps are hard-excluded by bundle id: `com.apple.keychainaccess`, `com.apple.Passwords`, `com.1password.1password`, `com.agilebits.onepassword7`, `com.bitwarden.desktop`, `com.lastpass.LastPass`, `com.dashlane.dashlane`, `org.keepassxc.keepassxc`, `com.keepersecurity.passwordmanager`, `in.sinew.Enpass-Desktop`, `com.nordpass.macos.NordPass`, `me.proton.pass.electron`, and also `com.apple.systempreferences` and `com.apple.SecurityAgent`. Also excluded: URL hosts for these vaults (`*.1password.com`, `vault.bitwarden.com`, `*.lastpass.com`, `passwords.google.com`, `account.proton.me`) and any URL with credentials in it (`user:pass@`).
